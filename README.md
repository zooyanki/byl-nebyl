# Быль и Небыль

Action-RPG в стиле Diablo II с пиксельной графикой на тему славянского фольклора и Северной Руси XI века.

**Акт I** — три миссии, браузерная игра, базовое разрешение 1920×1080, нативное 640×360 (масштаб ×3).

## Структура проекта

- `prototype/` — играбельный прототип на JS+Canvas (без сборки)
- `art/` — мокапы UI, палитры, генераторы (`art/teaser/` — заготовки тизера)
- `story/` — сюжет (act1.md)
- `design/` — стандарт масштабирования, план тизера, `design/gdd/` — игровой дизайн-документ
- `qa/` — материалы тестирования

## Как запустить прототип локально

Прототип должен быть запущен через HTTP-сервер (file:// не работает).

**Windows:**
```cmd
cd prototype
py -m http.server 8000
```

**Linux / macOS:**
```bash
cd prototype
./run.sh
```

или

```bash
cd prototype
python3 -m http.server 8000
```

Затем откройте в браузере: http://localhost:8000/

## Управление

| Ввод | Действие |
|---|---|
| ЛКМ | идти / атаковать нечисть «Сшибкой» |
| ЛКМ (держать 3 с) | освятить огнище в капище |
| ПКМ | навык (на старте «Огненный змей») |
| **F1–F6** | назначить навык из панели на ПКМ |
| **Пробел** | рывок на 3 тайла |
| **T** | окно «Навыки» (дерево из 2 ветвей) |
| 1–4 | выпить зелье из пояса |
| Alt / Z | подписи добычи |
| Tab / M | большая карта |
| I / C | котомка / окно «Витязь» |
| N | звук вкл/выкл |
| Esc | закрыть окна / пауза |

**Возрождение:** сначала у крады в Залесье, после касания Чурова камня (у входа в капище) — у камня.

Полное описание в `prototype/README.md`.
