# Быль и Небыль

Браузерная экшен-RPG в духе Diablo II: Северная Русь XI века, окрестности Ладоги, былины и славянский фольклор.

## Структура проекта

- **`prototype/`** — игровой прототип (грей-бокс итерация 2: навыки F1–F6, дерево навыков, 8 направлений, GDD v1.5)
- **`art/`** — исходники художника: спрайты, UI-макеты, кадры тизера
- **`design/`** — GDD, scale.md, teaser.md
- **`story/`** — акт I, тексты
- **`qa/`** — отчёты QA итераций 1–2

## Как запустить прототип

```sh
cd prototype
python3 -m http.server 8000
# открыть http://localhost:8000/
```

## Управление

| Ввод | Действие |
|---|---|
| ЛКМ | идти / атаковать нечисть «Сшибкой» |
| ПКМ | навык (на старте «Огненный змей») |
| **F1–F6** | назначить навык из панели на ПКМ |
| **Пробел** | рывок на 3 тайла |
| **T** | окно «Навыки» (дерево из 2 ветвей) |
| 1–4 | выпить зелье из пояса |
| Alt / Z | подписи добычи |
| Tab / M | большая карта |
| I / C | котомка / окно «Витязь» |
| N | звук вкл/выкл |
| Esc | закрыть окна / пауза |

См. полное описание в `prototype/README.md`.
