## Как поставить
1. `cp art/sprites/prop_stump_burnt/prop_stump_burnt.{png,json} prototype/assets/fx/`
2. `cd prototype && patch -p1 < ../art/layout/zalesye_mara_decor.patch` (или руками — ниже).

```js
// map.js, carveMaraDen(), после двух циклов по den.ash:
for (const [x, y, v] of den.stumps || []) m.addProp('stump', x, y, 1, { fp: [x + 0.5, y + 0.5, 0, 0], variant: v | 0 });
// rest_fx.js, SHEETS:
stump: 'prop_stump_burnt',
// props.js: import { drawRestSource, drawFxFrame } from './rest_fx.js'; в drawProp перед запеканием:
if (p.type === 'stump') { const [x, y] = toS(p.x + 0.5, p.y + 0.5); if (!drawFxFrame(ctx, 'stump', p.variant || 0, x, y, { flip: p.seed > 0.5 })) ashPile(ctx, p, toS); return; }
// propHeight: ..., anvil: 16, stump: 18 }
```
`zalesye.json` → `landmarks.maraDen`: `ash` и новое поле `stumps` из `zalesye_mara_decor.json` (поля с `_` — комментарии).
Только пепел без кода: достаточно заменить `ash` — пропы `ash` уже рисуются.

## Правила раскладки
* Весь декор **без коллизии** (fp 0×0); проходимость с декором и без него совпадает побитно (`check_layout.py`).
* Координаты кратны ½. `markRect` при нецелых `x·2` и `y·2` даже у пустого fp помечает сабтайл. **Сейчас так у 3 из 8 точек пепла** (38,2; 18,8), (36,8; 18,2), (46,2; 17,6). Это невидимые стенки в ½ тайла на (37; 18,5), (38,5; 19) и посреди горловины на (46,5; 18). Патч заменяет эти точки.
* Горловина: 8 пятен, x 36–49 (центры 36,5…48,5), y 17–19, шаг 2 → 3,5 → 2 → 1,5 → 1 → 1 → 1: реже у деревни, гуще к Огнее. Разрыв 3,5 — камень 2×2 на x 39–41 (сид карты); пятно под ним не видно.
* Край поляны: 13 пней + 9 кучек пепла на r 7,0–8,6 от (56,5; 16,5), группами с разрывами. Вход с запада (углы 143°–196°, горловина) пуст, круг обхода r 6 свободен. Все точки внутри поляны и при `clearR` 8,9, и при 9. При старом 8,2 шесть пней и две кучки попали бы в чащу.
