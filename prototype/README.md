# «Быль и Небыль» — грей-бокс прототип, итерация 2

Браузерная экшен-RPG в духе Diablo II: Северная Русь XI века, окрестности Ладоги, былины и славянский фольклор.
Локация — «Залесье» (акт I «Ладога», миссия 1). Всё нарисовано простыми фигурами (грей-бокс) в палитре
`art/ui/palette_v2.json`; окна, кнопки и иконки предметов выгружены из исходников художника. Нативное разрешение
640×360, целочисленный масштаб ×3 (1920×1080), изометрия 2:1 (тайл 32×16).

## Как запустить

Нужен только Python 3 и любой современный браузер. Сборки, внешних зависимостей и CDN нет: чистые ES-модули,
Canvas 2D и WebAudio. Балансные конфиги `data/*.json` грузятся через `fetch()` при старте.

```sh
cd /workspace/game/prototype
./run.sh              # или: python3 -m http.server 8000
# открыть http://localhost:8000/
```

Открыть `index.html` двойным щелчком нельзя: браузер не грузит ES-модули и JSON по `file://`.

Параметры адреса: `?debug` — FPS; `?seed=N` — детерминированная случайность (для отладки и автотестов).
В консоли доступен `window.__game` (состояние игры, `give(база, редкость, {affixes})`, `dropRandom(ilvl)`,
`clientOf(x, y)`, `dbg.CFG` — загруженные конфиги).

## Управление

| Ввод | Действие |
|---|---|
| ЛКМ по земле / зажать ЛКМ | идти (путь A* по полутайловой сетке, обходит нечисть) |
| ЛКМ по нечисти (можно держать) | подойти и бить оружием |
| Shift + ЛКМ | бить на месте (по нечисти под курсором) |
| ЛКМ по предмету или подписи | подойти и поднять в котомку; серебро подбирается само в радиусе 1 тайла |
| ПКМ (можно держать) | «Огненный змей»: снаряд с взрывом радиусом 1 тайл, 5 Яри |
| 1–4 (или щелчок по ячейке пояса) | выпить зелье из пояса |
| Alt (держать) | подписи всей добычи на земле; без Alt подписан только предмет под курсором |
| Z | подписи добычи «всегда» / «по Alt» (запоминается) |
| Tab или M | большая карта поверх мира (как в D2) |
| I или B / C | котомка со снаряжением / окно «Витязь» (свойства и показатели) |
| N | звук вкл/выкл (запоминается) |
| T / J | навыки / летопись — заглушки «в следующей итерации» |
| Esc | закрыть карту или окна, иначе пауза (в паузе — переключатели «Звук», «Подписи», «Мини-карта») |
| Кнопки C/I/T/M/J/ESC под мини-картой | то же, что клавиши; при наведении — подсказка |

При потере фокуса окна игра встаёт на паузу (GDD §4.1).

**В котомке:**
- щелчок по предмету берёт его на курсор; щелчок по клетке кладёт (с обменом, если под ним ровно один предмет);
- щелчок по слоту куклы надевает (если не подходит: «Сюда это не надеть» / «Требуется уровень N»);
- можно и перетаскивать: зажать, протащить, отпустить;
- ПКМ по предмету в котомке надевает его в подходящий слот (зелье — выпивает); ПКМ по слоту снимает в котомку;
- щелчок по миру с предметом на курсоре выбрасывает его на землю;
- при закрытии окна предмет с курсора возвращается в котомку.

## Что сделано в итерации 2

### Бой и физика
- **Полутайловая сетка** по `design/scale.md`: проходимость по сабтайлам 16×8 (½ тайла), A* с шагом 0,5 тайла,
  радиусы тел (герой 0,30, анчутка 0,25, упырь 0,35). Тонкие стены развалин и стена у старта толщиной ½ тайла:
  можно встать в свободной половине тайла. Стволы деревьев — ½×½ тайла, крона проходима. Если щёлкнуть в стену,
  герой подходит к ней вплотную.
- **Нечисть преграждает путь**: герой и враги — твёрдые тела, сквозь друг друга не проходят. Путь героя обходит
  тела; упёршийся в сородича враг обходит его по пути.
- **Взрыв «Огненного змея» не бьёт через стены**: снаряд взрывается перед препятствием, урон получает только тот,
  до кого есть прямая видимость от центра взрыва.
- **Хит-стоп 50 мс** (на удачном ударе — дольше), **отбрасывание** (лёгкие отлетают дальше), лёгкая тряска экрана,
  оглушение врага на 0,25 с от удара > 10% его жизни (не чаще раза в 1,5 с), героя — на 0,2 с от удара > 12%.
- **Анчутка** держит дистанцию и кидает угли (дальность 4, снаряд 8 тайлов/с, огонь; от угля можно уйти), после
  броска с шансом 30% отбегает на 2–3 тайла, при гибели сородича рядом с шансом 30% с визгом удирает на 3 с.
  **Упырь** медленный (2,5 тайла/с), бьёт больно (урон ×1,2), иммунен к порче.
- **Мини-карта** в углу (как на макете HUD v2) с туманом разведки, метками нечисти, заговорённой и лучшей добычи и крады; большая
  карта поверх мира по Tab. Под мини-картой — плашка зоны и кнопки меню.
- **Звуки-заглушки WebAudio** (синтез, без файлов): удар, удачный удар, промах, блок, получение урона, каст,
  взрыв, бросок угля, гибель врага, подбор, серебро, зелье, снаряжение, новый уровень, смерть, возвращение, щелчок UI.

### Гибель (GDD §4.5)
- Экран «Пал ты, дружинник…» с кнопкой «Очнуться у крады» (или Enter) через 1,5 с.
- **Штраф: −10% носимого серебра**, округление вверх (из 101 теряется 11). Опыт и снаряжение не теряются,
  трупа и выбегания за вещами нет.
- Возвращение **у огня крады** — замена Ладоги, пока в прототипе одна зона. Полные Жизнь и Ярь,
  **2 с неуязвимости**; погнавшаяся нечисть теряет след и уходит к логову.
- **Нечисть не возрождается по таймеру.** Перебитые стаи собираются заново только при возвращении у крады —
  замена правила GDD «при повторном входе в зону».

### Котомка и снаряжение
- Окно **«Котомка»** по макету `mockup_inventory_v2`: кукла с 10 слотами (Голова, Шея, Тело, Десница, Шуйца,
  Руки, 2 перстня, Пояс, Ноги) и сетка **10×4 по 24 px**. Предметы занимают клетки по размеру (меч 1×3,
  кольчуга 2×3, шелом 2×2, пояс 2×1, перстень 1×1). Внизу «Места: n/40» и серебро.
- Окно **«Витязь»** по макету `mockup_character_v2`: уровень, опыт, свойства с кнопками [+] (5 очков за уровень),
  показатели (урон ЛКМ/ПКМ, меткость, шанс попасть по врагу своего уровня, защита, удачный удар, жизнь, Ярь)
  и сопротивления. Вложение очков сразу пересчитывает показатели.
- **Характеристики от вещей**: урон и скорость оружия, броня → защита, блок щитом, +жизнь, +Ярь, свойства,
  сопротивления, кровопийство, возврат урона, скорость атаки, бега и ведовства, урон огнём и холодом, MF.
- **Подсказки на русском** с цветом редкости (Простой — лён, Заговорённый — голубой, Дивный — пламя): база,
  урон или броня, скорость, требование (красным, если не дорос), свойства, сравнение с надетым
  («Средний урон: +2 к надетому» — зелёным или красным).
- Открытая панель сдвигает героя в свободную половину экрана, как в D2.
- Стартовый комплект по GDD §6.2: скрамасакс, малый щит, шелом-шишак, короткая кольчуга; в поясе 3 слабых зелья
  жизни и 2 слабых зелья Яри.

## Расхождения с GDD и допущения

- Посохов (3 базы, двуручные) нет — нет иконки и правила «щит недоступен с посохом»; баз 24 из 28 (+3 посоха;
  вторая база шеи «Гривна» есть). Былинные предметы не выпадают (былинная редкость превращается в дивную).
- Дерева навыков нет: ранг «Огненного змея» растёт сам (1 + ⌊(ур.−1)/2⌋), P10 «Вещий» даёт +ранг к нему,
  «Ратный» — без эффекта. На 10-м ранге GDD даёт 33–51, а «+3–5 за ранг» даёт 33–46: взят рост +3/+4,
  совпадающий с рангом 5 (18–26).
- Возвращение у крады вместо Ладоги; репопуляция при возвращении вместо «при входе в зону».
- Трекер — заглушка «Очисти Залесье N/M»; цели act1 (избы, Мал, Мара Пепельная) — миссионный контент, позже.
- Береста возврата не реализована: её доля выпадения отдана зелью жизни; на старте 3 бересты не выдаются.
- Правило выбора базы по ilvl (треб. ≤ ilvl+3, вес 4 для треб. ≤ ilvl) — моё допущение, в GDD его нет.
- Анчутка «держит дистанцию»: кроме 30% отскока после броска, она отходит всегда, если герой ближе 2,2 тайла.
- У упыря GDD пишет «огонь по нему −25% (Res −25%)»: принято как сопротивление +25% (урон огнём меньше).
- Уставные заголовки окон взяты с макетов («ВИТЯЗЬ», «КОТОМКА», подпись «Дружинник-ведун · Ладога»);
  в GDD окна названы «Герой» и «Снаряжение». Подсказки кнопок используют названия макета.
- Каст 0,8 с: снаряд вылетает на 0,3 с, остаток анимации можно прервать ходьбой.

## Известные ограничения

- В грей-боксе у героя и врагов только два направления взгляда; внешность от снаряжения не меняется (так и в GDD v2).
- Большая карта (Tab) — линии поверх мира без затемнения; при ярком освещении читается слабо.
- Подписи добычи могут лечь поверх героя или врага; щелчок по подписи важнее щелчка по врагу (как в D2).
- `?seed` фиксирует случайность, но бой в реальном времени немного зависит от частоты кадров.
- Производительность: в headless Chrome без GPU кадр ~6 мс; дороже всего освещение.
- Звук начинает работать после первого щелчка или клавиши (политика браузеров для WebAudio).
