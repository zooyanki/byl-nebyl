## 1. Видение и ключевые принципы

**Логлайн [ПЛЕЙСХОЛДЕР]:**
> «Было ли, не было…» Под Старой Ладогой проснулись древние сопки, и грань между Былью и Небылью дала трещину. Сторожевые огни гаснут, из курганов встают упыри, в Чёрном бору хозяйничает обезумевший Леший, а за рекой Смородиной ждёт своего часа Бессмертный Навий Князь. Дружинник-ведун, наученный и мечу, и старому слову, идёт заткнуть разлом, пока Навь не хлынула в мир людей.

## 2. Core loop

```
 ┌───────────────────────── СТАРАЯ ЛАДОГА ─────────────────────────┐
 │ кузнец/купец: продать, купить → знахарка: отвары → подклет → волхв │
 └──────┬─────────────────────────────────────────────▲───────────┘
        │ Чуров камень / ворота                       │ береста возврата, гибель, Чуров камень
        ▼                                             │
 ЗОНА МИССИИ (Быль → Небыль): исследовать → бой → добыча → уровень → матёрые/событие → босс
        └────────── котомка полна / отвары кончились ──┘
```

| Цикл | Длина | Содержание | Награда |
|---|---|---|---|
| Микро | 5–20 с | Пачка из 3–7 врагов: подойти, навык, отвар, добить | Опыт, серебро, 0–2 предмета |
| Средний (вылазка) | 8–15 мин | Пройти часть зоны, наполнить котомку, вернуться | Уровень, заговорённые и дивные вещи |
| Большой (миссия) | 40–65 мин | Цели и босс | Очко навыка, гарантированный дроп, следующая миссия |

В город игрок возвращается 2–3 раза за миссию: котомка 10×4 заполняется за 12–15 минут, запас пояса 4×5 расходуется за 10–15 минут.

## 3. Персонаж

### 3.1. Класс

**В v1 один класс: «Дружинник-ведун» [ПРЕДЛОЖЕНИЕ, имя — ПЛЕЙСХОЛДЕР].** Это ладожский дружинник, которого в детстве учил старый волхв. Он бьётся и мечом, и словом.

Две ветки навыков:
- **«Ратное дело»** — ближний бой, щит, обереги;
- **«Ведовство»** — сварожий огонь, Морозкин холод, Перунова молния, через резы и наговоры.

Внешний вид **[ЕСТЬ: спрайт v2]**: конический шелом с наносником, кольчуга, красный плащ, круглый щит, меч.

Почему один класс:
1. Анимации героя — самая дорогая часть арта (≈ 300 кадров на класс).
2. Баланс и QA для каждого класса делаются заново.
3. Две ветки дают три стиля игры: рубака, ведун и гибрид.

Во v2 возможны классы «Охотница-лучница» (лук, сулицы, ловушки), «Волхв» (чистый кастер, призыв духов) или «Варяг-наёмник» (двуручная секира, ярость).

### 3.2. Характеристики

| Характеристика | Старт | Эффект за 1 очко |
|---|---|---|
| **Мощь** (STR) | 20 | +1% физического урона |
| **Ловкость** (DEX) | 20 | +5 к меткости (AR), +0,1% к шансу крита, +1 к защите за каждые 4 DEX |
| **Живучесть** (VIT) | 25 | +2 к макс. HP («Жизнь») |
| **Дух** (ENE) | 15 | +2 к макс. Силе (мана), +1% к урону ведовства |

В v1 у предметов есть только требование по уровню.

### 3.3. Производные параметры и формулы (без изменений относительно 1.0)

| Параметр | Формула |
|---|---|
| Макс. Жизнь (HP) | `20 + 2·VIT + 4·(Lvl−1) + HP с предметов`, затем `× (1 + %HP)` |
| Макс. Сила (мана) | `10 + 2·Дух + 2·(Lvl−1) + с предметов` |
| Восстановление Силы | `1,5% макс. Силы/с × (1 + %восст.)` |
| Восстановление Жизни | 0 (только отвары, кровопийство, знахарка) |
| Меткость AR | `5·DEX + 5·Lvl + AR с предметов`, затем `× (1 + %AR навыка)` |
| Защита DEF | `Σ брони + floor(DEX/4)`, затем `× (1 + %DEF «Чур-оберега»)` |
| Шанс попадания (только физ.) | `Hit = clamp( 2·AR_A/(AR_A+DEF_D) · Lvl_A/(Lvl_A+Lvl_D), 5%, 95% )` |
| Ведовство (снаряды) | Попадает всегда при касании снаряда. Уклонение движением |
| Крит | `5% + 0,1%·DEX + бонусы`, кап 50%, множитель ×1,5 |
| Физ. урон | `rand(min,max оружия + плоский) × (1 + Мощь/100 + %ED) × Множ_навыка × Крит` |
| Урон ведовства | `rand(min,max навыка) × (1 + Дух/100 + %урона ведовства) × Крит` |
| Стихийный урон оружия | Прибавляется отдельно, на него не действуют Мощь и %ED |
| Сопротивления: **огонь**, **холод**, **порча** | `Урон × (1 − Res)`, Res от −100% до кап 75%, старт 0% |
| Блок щитом | Шанс блока щита, кап 50%. Блок отменяет удар ближнего боя или стрелу |
| Скорость атаки / ведовства / бега | Атаки/с оружия × (1+%IAS), кап +50% / каст 0,8 с × (1−%FCR), кап −30% / 4,5 тайла/с × (1+%), кап +30% |
| Оглушение от удара | Удар > 12% макс. HP героя прерывает его на 0,2 с. Монстра прерывает удар > 10% его HP (0,25 с, не чаще раза в 1,5 с, боссы не прерываются) |

Порядок расчёта: база → плоские бонусы → проценты → крит → сопротивления. Округление вниз, минимум 1.

### 3.4. Очки и сброс

## 4. Боёвка

### 4.1. Управление (без изменений)

| Shift + ЛКМ | Атака на месте |

| Пробел | Рывок |

| Alt (удержание) / Z | Подписи предметов на земле |
| C / I / T / M / ESC | Витязь (персонаж) / Котомка (инвентарь) / Навыки / Карта / Меню **[ЕСТЬ: кнопки]** |
| Tab / J | Наложение карты / Летопись (журнал заданий) |

Контекстное меню браузера отключено, при потере фокуса игра ставится на паузу.

### 4.2. Атака

Без изменений относительно 1.0:
- удар засчитывается на 60% анимации, радиус ближнего боя 1,2 тайла;
- отклик на попадание: вспышка, хит-стоп 50 мс, числа урона;
- цвета чисел: белый — обычный, жёлтый — крит, оранжевый — огонь, голубой — холод, зелёный — порча;
- при промахе надпись «Мимо».

### 4.3. Движение и рывок

- Всегда бег, 4,5 тайла/с, путь ищется через A*.
- **Рывок [ПРЕДЛОЖЕНИЕ]:** Пробел, 3 тайла за 0,2 с, неуязвимость 0,15 с в начале, КД 4 с, Силы не стоит, сквозь стены не проходит.
- Все опасные атаки телеграфируются за 0,6–1,2 с: у Были красный контур, у Небыли зелёный.

### 4.4. Отвары и береста

| Предмет [ПЛЕЙСХ.] | Эффект | Время | Цена (серебро) | Источник |
|---|---|---|---|---|
| Слабый / Целебный / Крепкий отвар (иконка `life`) | +45 / +90 / +160 HP | за 3 с | 15 / 40 / 90 | Дроп по mlvl (1–7 / 6+ / 12+), знахарка |
| Слабый / обычный / крепкий отвар Силы (`mana`) | +30 / +60 / +110 Силы | за 3 с | 15 / 40 / 90 | Аналогично |
| **Живая вода** (`zhivaya` **[ЕСТЬ]**) | +35% HP и Силы мгновенно | мгновенно | не продаётся | 10% дропа отваров |
| **Береста возврата** (свиток портала) | Открывает Чуров проход в Ладогу и обратно на 60 с | каст 1 с | 25 | Купец, знахарка, дроп |

- Пояс: 4 ячейки по 5 отваров одного вида **[ЕСТЬ]**.
- КД 0,5 с, отвары одного вида не складываются (новый перезапускает таймер с остатком).
- На старте: 3 слабых целебных отвара, 2 слабых отвара Силы, 3 бересты.

### 4.5. Гибель

### 8.2. Миссия 1 «Огонь на капище»

**Цели (в трекере):**
1. Разожги сторожевые костры 0/3.
2. Разожги краду на капище.
3. Упокой Курганного Владыку и закрой разлом Небыли.

**Ход:**
1. Велимудр рассказывает: на сопках погасли сторожевые костры, из Великой сопки лезет нечисть, на дорогах бесчинствуют варяги-изгои.
2. На трёх холмах стоят сторожевые костры. Розжиг: удерживать 3 с, урон прерывает. После розжига набегает волна из 6–8 анчуток. Третий костёр стережёт Серогрив-волколак. В разорённом селе засел атаман изгоев.
3. Когда горят все три, можно разжечь краду у чур-идола на древнем капище **[ЕСТЬ: крада и идол в сцене v2]**. Огонь крады отпирает вход в Великую сопку (тряска экрана, реплика).
4. Великая сопка: 1 уровень, затем Погребальный чертог. После смерти Курганного Владыки разлом Небыли схлопывается **[ЕСТЬ: разлом в сцене v2]**.

Обучение (одноразовые подсказки): движение, атака, подбор, отвар при HP < 50%, уровень, навыки, береста, кузнец.

**Награда:** +1 очко навыка, 300 серебра, при первом убийстве дивный предмет с босса, открытие М2, сброс у знахарки. Заветный предмет **«Уголёк крады»** (сюжетный, не занимает ячейку): Велимудр по нему узнаёт, откуда идёт Небыль.

### 8.3. Миссия 2 «Гиблая топь»

**Цели:**
1. Найди затопленное городище в Чёрном бору.
2. Ударь в вечевое било.
3. Одолей Лешего Дикобора.

Необязательно: разори 3 кикиморьих гнезда. За все три кованый сундук и строка в летописи.

**Ход:**
1. Чёрный бор: ельник с берёзами переходит в топь с гатями. В воду войти нельзя. Ориентиры: мельница, гнёзда кикимор.
2. Кикимора-Шептуха караулит у била.
3. Удар в било созывает «всех, кто в топи», и начинается **оборона на 60 с**: 4 волны, в 3-й волне матёрые.
4. После обороны вода уходит и открывается тропа в Бурелом Лешего.
5. Леший в конце боя приходит в себя: «Не своей волей я…» [сценарист]. Он укажет путь к реке Смородине.

**Награда:** +1 очко навыка, 600 серебра. Велимудр даёт выбрать 1 из 3 предметов: заговорённый перстень, заговорённую гривну или дивный пояс, ilvl 11. Открывается М3.

### 8.4. Миссия 3 «За Смородиной»

**Цели:**
1. Перейди Калинов мост.
2. Погаси навьи огни 0/3 (зелёное пламя Небыли; зеркально кострам М1).
3. Одолей Навьего Князя.

**Ход:**
1. Порубежье: мёртвый берег, отступники, разбойники в их найме, упыри. В конце зоны Калинов мост через огненную реку Смородину. Это сет-пис: переход в Небыль, палитра сдвигается в холод и зелень.
2. Навье капище: два навьих огня, идолища-истуканы в кругу.
3. Костяные чертоги: третий огонь и Мракута-отступница.
4. Погасить огонь — удерживать 3 с, после чего выходят матёрые отступники.
5. Когда погашены все три, открывается Чертог Князя.
6. Бой в 3 фазах с «Смертью в игле» (§5.4). Заветный предмет **«Игла Бессмертного»** выпадает из ларца, на ней сюжетный финал.
7. Эпилог («…и я там был, мёд-пиво пил» — по мотивам сказочной концовки, текст сценариста). Экран «Акт I пройден» со статистикой и тизером акта II.

**Награда:** +1 очко навыка, 1 000 серебра, гарантированный былинный предмет при первом убийстве, режим «Охота».

### 8.5. Генерация уровней: ручная с рандомизацией (без изменений)

- Карты делаются вручную в Tiled.
- Рандомизируется наполнение: 25–40 маркеров врагов на зону (активно 70%), 30% пачек становятся элитками, 6 из 12 сундуков, имена и модификаторы вожаков.
- Сид показывается в меню ESC.
- Процедурная генерация — во v2.

### 8.6. Пост-гейм «Охота»

После М3 зоны перезаселяются при входе через Чуров камень, боссов можно убивать повторно. Название режима на выбор сценаристу: «Охота» или «Ратные походы».

### 12.3. Тестировщик (чек-листы из 1.0 + новые пункты)

Дебаг-консоль `~` в dev-сборке: `level`, `xp`, `silver`, `give`, `tp`, `god`, `kill_all`, `quest`, `sim_drop`, `show_hitboxes`, `seed`, `fps`.

**A. Прохождение и прогрессия.**
- [ ] Каждая миссия проходится, ничего не застревает. Костры, крада, било, мост, навьи огни и ларец срабатывают и после гибели или загрузки.
- [ ] Уровни на выходе из миссий: 6–7 / 11 / 15–16 (±1).
- [ ] XP по §3.5, очки за уровень и миссии, один сброс, лимит рангов.

**B. Бой.**
- [ ] Шанс попасть в пределах 5–95%, окно «Витязь» совпадает с практикой (±7%).
- [ ] Все 8 навыков на рангах 1, 5 и 10 соответствуют §3.6, включая урон при приземлении «Перунова скока».
- [ ] Капы сопротивлений, блока и скоростей.
- [ ] Рывок и скок не проходят сквозь стены.
- [ ] Отвары: стек, КД, автозаполнение пояса.
- [ ] Гибель: −10% серебра только из котомки.

**C. Враги и боссы.**
- [ ] AI по §5.2: бегство анчуток, отскок волков, дистанция лучников, засада идолищ, подъём анчуток кикиморой.
- [ ] Возврат через 25 тайлов, телеграфы двух цветов видны вовремя.
- [ ] Фазы боссов. «Смерть в игле»: HP Князя не опускается ниже 30%, пока цел ларец. Ларец не исчезает при гибели героя. Повторный бой начинается с полного HP Князя и нового ларца.
- [ ] TTK боссов в пределах ±25% от §9.2.

**D. Добыча и торговля.**
- [ ] `sim_drop` совпадает с §6.7.
- [ ] Аффиксы в диапазонах тиров. **Род префикса верен для всех 28 баз** («Калёная секира», «Калёные поршни»).
- [ ] Гарантированный дроп боссов. Заветные предметы нельзя продать или выбросить.
- [ ] Сетка котомки, посох снимает щит.
- [ ] Цены, выкуп, разный ассортимент у кузнеца и купца.

**E. Сохранения.**
- [ ] Автосейв, резервный ключ, экспорт и импорт, миграция, вторая вкладка, пустой профиль.

**F. UI и русский язык (новое).**
- [ ] Все строки берутся из `ru.json`: в интерфейсе ни одного английского слова и ни одного «сырого» ключа.
- [ ] Кириллица: ё, й, щ, ъ, заглавные в уставном шрифте читаются при ×2, ×3 и ×4.
- [ ] Длинные слова («Каменнокожий», «Восстановление Силы») не вылезают за плашки, тултипы, кнопки и трекер.
- [ ] Склонение после чисел: «1 отвар / 2 отвара / 5 отваров», серебро.
- [ ] Масштабы и нестандартные разрешения, горячие клавиши, ПКМ без меню браузера, пауза при потере фокуса.

**G. Производительность.**
- [ ] 60 FPS в обычном бою, ≥ 45 FPS в фазе 3 у Князя.
- [ ] Загрузка ≤ 10 с, переходы между зонами ≤ 2 с.
- [ ] Память: рост ≤ 50 МБ за 60 минут.
