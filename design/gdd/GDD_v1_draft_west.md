## 2. Core loop

```
 ┌────────────── ГОРОД (Тлеющий Брод) ───────────────┐
 │ продать лут → купить зелья/вещи → сундук → квест   │
 └──────┬──────────────────────────────────▲─────────┘
        │ путевой камень / выход           │ свиток портала, смерть, путевой камень
        ▼                                  │
 ЗОНА МИССИИ: исследовать → бой с пачкой → лут → (уровень? → очки) → элитка/событие → босс
        └────── инвентарь полон / зелья кончились ──┘
```

| Цикл | Длина | Содержание | Награда |
|---|---|---|---|
| Микро (бой) | 5–20 с | Пачка из 3–7 врагов: подойти, навык, зелье, добить | Опыт, золото, 0–2 предмета |
| Средний (вылазка) | 8–15 мин | Пройти часть зоны, заполнить инвентарь, вернуться в город | Уровень, магические и редкие вещи, золото на зелья |
| Большой (миссия) | 40–65 мин | Цели миссии и босс | Очко навыка, гарантированный дроп, открытие следующей миссии |

Сколько раз игрок ходит в город: в среднем 2–3 раза за миссию. Причины: инвентарь 10×4 заполняется примерно за 12–15 минут, а запас зелий в поясе (4×5) расходуется за 10–15 минут.

## 3. Персонаж

### 3.1. Классы

**Решение: в v1 один класс, «Храмовник пепла» [ПРЕДЛОЖЕНИЕ, имя — ПЛЕЙСХОЛДЕР].** У него две ветки навыков: «Сталь» (ближний бой) и «Пепел» (огонь и лёд). Получаются два билда, а работы как на один класс.

Почему не два класса:
1. Главная стоимость класса в арте. Анимации героя в 5 направлениях: ≈ 200 кадров на класс (§12.1). Второй класс удваивает самую дорогую часть работы художника.
2. Каждый класс нужно балансить отдельно, а тестировщик проходит акт заново за каждый.
3. Макет **[ЕСТЬ]** уже показывает гибрида: латник с огненным посохом, навыки Bash/Whirlwind/Holy Shield и Fireball/Icebolt/Teleport на одной панели.
4. Две ветки с вложением очков в любую из них дают три стиля игры: мили, кастер и гибрид.

Второй класс (например, «Охотница», лук и ловушки) переносим в v2 (§13).

### 3.2. Характеристики

Четыре классических характеристики. На старте у каждой базовое значение, за уровень игрок получает 5 свободных очков.

| Характеристика | Старт | Эффект за 1 очко |
|---|---|---|
| Сила (STR) | 20 | +1% физического урона |
| Ловкость (DEX) | 20 | +5 к рейтингу атаки (AR), +0,1% к шансу крита, +1 к защите за каждые 4 DEX |
| Живучесть (VIT) | 25 | +2 к макс. HP |
| Энергия (ENE) | 15 | +2 к макс. мане, +1% к урону заклинаний |

В v1 предметы требуют только уровень, требований по STR/DEX нет. Так проще балансировать и проще интерфейс.

### 3.3. Производные параметры и формулы

| Параметр | Формула |
|---|---|
| Макс. HP | `20 + 2·VIT + 4·(Lvl−1) + HP с предметов`, затем `× (1 + %HP)` |
| Макс. мана | `10 + 2·ENE + 2·(Lvl−1) + мана с предметов` |
| Реген маны | `1,5% макс. маны/с × (1 + %реген)` |
| Реген HP | 0 (только зелья, вампиризм и лекарь) |
| Рейтинг атаки AR | `5·DEX + 5·Lvl + AR с предметов`, затем `× (1 + %AR навыка)` |
| Защита DEF | `Σ брони с предметов + floor(DEX/4)`, затем `× (1 + %DEF от «Священного щита»)` |
| Шанс попадания (атакующий A по цели D, только физ. атаки) | `Hit = clamp( 2 · AR_A/(AR_A+DEF_D) · Lvl_A/(Lvl_A+Lvl_D), 5%, 95% )` |
| Заклинания | Попадают всегда, если снаряд коснулся цели. От них можно увернуться движением |
| Крит | `Шанс = 5% + 0,1%·DEX + бонусы`, кап 50%. Множитель ×1,5. Критуют физические атаки и заклинания |
| Физ. урон атаки | `rand(min,max оружия + плоский урон) × (1 + STR/100 + %ED оружия) × Множитель_навыка × Крит` |
| Урон заклинания | `rand(min,max навыка) × (1 + ENE/100 + %урона закл.) × Крит` |
| Стихийный урон от оружия | Прибавляется к удару отдельно, на него не действуют STR и %ED |
| Сопротивления (огонь, холод, яд) | `Урон × (1 − Res)`, Res от −100% до кап 75%. Старт 0% |
| Физ. снижение урона | Только у врагов-модификаторов («Каменная кожа»). У героя в v1 нет |
| Блок щитом | `Шанс блока щита`, кап 50%. Блок полностью отменяет физический удар ближнего боя или стрелу |
| Скорость атаки | `атак/с оружия × (1 + %IAS)`, кап +50% |
| Скорость каста | Базово 0,8 с на каст (1,25/с) `× (1 − %FCR)`, кап −30% |
| Скорость бега | 4,5 тайла/с `× (1 + %скорости)`, кап +30% |
| Оглушение от удара | Удар > 12% макс. HP героя прерывает действие на 0,2 с. Монстра прерывает удар > 10% его HP (0,25 с, не чаще раза в 1,5 с; боссы не прерываются) |

Порядок расчёта: база → плоские бонусы → проценты → крит → сопротивления. Все результаты округляются вниз, минимум 1.

### 3.4. Очки и сброс

- За уровень: **+5 очков характеристик и +1 очко навыка.** Ещё **+1 очко навыка** за каждую миссию (всего +3).
- Очков навыков к 16 уровню: 15 + 3 = **18**, к 20 уровню: **22**.
- **Один бесплатный сброс** навыков и характеристик у лекаря, становится доступен после миссии 1. Нужен, чтобы игрок и тестировщики могли попробовать другой билд.

### 3.6. Дерево навыков v1

## 4. Боёвка

### 4.1. Управление [ПРЕДЛОЖЕНИЕ, раскладка согласована с макетом]

| Ввод | Действие |
|---|---|
| ЛКМ (клик или удержание) | Идти в точку. По врагу: подойти и атаковать навыком ЛКМ (по умолчанию базовая атака). По предмету: подойти и поднять. По NPC или объекту: взаимодействие |
| Shift + ЛКМ | Атаковать на месте в сторону курсора, без движения |
| ПКМ (клик или удержание) | Применить навык ПКМ в точку курсора или по цели |
| F1–F6 | Назначить навык на ПКМ (как в Diablo II). Опция в настройках: «Мгновенный каст», тогда F-клавиша сразу применяет навык в курсор |
| Колесо мыши | Перебор навыков на ПКМ |
| Пробел | Рывок (§4.3) |
| 1–4 | Выпить зелье из ячейки пояса |
| Alt (удержание) / Z (переключатель) | Показать подписи всех предметов на земле |
| C / I / T / M / ESC | Персонаж / инвентарь / навыки / карта / меню **[ЕСТЬ: кнопки на макете]** |
| Tab | Наложение карты поверх экрана (как в D2) |
| J | Журнал квестов |
| ЛКМ по предмету в инвентаре / Shift + ЛКМ / ПКМ | Взять / положить в сундук или продать (когда открыто окно торговли) / надеть |

- Контекстное меню браузера в игре отключено.
- При потере фокуса вкладки игра ставится на паузу (одиночная игра).
- Переназначение клавиш в v1 не делаем, кроме переключателя «Мгновенный каст».

### 4.2. Атака

- **Базовая атака:** анимация длиной `1 / атак_в_секунду`, удар засчитывается на 60% анимации. Радиус ближнего боя 1,2 тайла.
- **Отклик на попадание (обязательно, пилон P1):** вспышка спрайта цели белым на 2 кадра, хит-стоп 50 мс у атакующего и цели, всплывающее число (белое — обычный, жёлтое крупное — крит, оранжевое — огонь, голубое — холод, зелёное — яд), звук.
- **Промах:** серая надпись «Мимо».
- **Таргетинг:** при клике ищем врага в радиусе 0,5 тайла от курсора, приоритет у ближайшего к курсору. Удержание ЛКМ на враге продолжает атаку, даже если курсор сполз.

### 4.3. Движение, рывок

- Режим один: всегда бег, 4,5 тайла/с. Выносливости в v1 нет. Путь ищется через A* по тайловой сетке.
- **Рывок [ПРЕДЛОЖЕНИЕ, в D2 этого нет]:** Пробел, рывок на 3 тайла в сторону курсора за 0,2 с, неуязвимость 0,15 с в начале, КД 4 с, маны не стоит, сквозь стены и врагов не проходит. Нужен для уклонения от телеграфированных атак боссов. Если руководитель захочет чистый D2, рывок убираем, а телеграфы боссов замедляем на 30%.
- Все опасные атаки боссов и элиток телеграфируются: красный контур на земле за 0,6–1,2 с до удара.

### 6.10. Цены и торговец

### 8.2. Миссия 1: «Горящий курган»

- **Цель (как в трекере, [ЕСТЬ]):** 1) Разжечь маяки 0/3. 2) Убить Костяного Стража.
- **Ход миссии:**
  1. Брифинг у Одрана.
  2. Пустошь: 3 маяка в трёх концах карты. У каждого засада. Розжиг — удерживать взаимодействие 3 с, полученный урон прерывает. После розжига появляется волна из 6–8 Падших. Маяк № 3 охраняет Клык Пепла.
  3. После 3 маяков открывается печать кургана.
  4. Курган: 1 уровень и босс.
- **Обучение (подсказки в духе D2, всплывают один раз):** движение, атака, подбор лута, зелья (при первом HP < 50%), уровень и очки, навыки, свиток портала, торговец.
- **События:** розжиг маяков, открытие печати (реплика и тряска экрана), вход в Зал Стража (дверь закрывается, реплика босса).
- **Награда:** +1 очко навыка, 300 золота, дроп босса (гарантированный редкий при первом убийстве), открытие М2, бесплатный сброс у лекаря.

### 8.3. Миссия 2: «Колокол топи»

- **Цели:** 1) Найти Затопленную часовню. 2) Ударить в колокол (засада). 3) Убить Мать-Трясину. Необязательно: сжечь 3 тотема Падших (сундук-реликварий за все три).
- **Ход:** топь с узкими гатями и водой, в которую нельзя зайти. Ориентиры: мельница, тотемы. Хрипун Гнилозуб у колокольни. Удар в колокол запускает **оборону на 60 с**: 4 волны из часовни, в 3-й волне пачка чемпионов. После обороны открывается спуск в Логово.
- **Награда:** +1 очко навыка, 600 золота, Одран даёт выбрать 1 из 3 предметов (магическое кольцо, магический амулет, редкий пояс, ilvl 11), открытие М3.

### 8.4. Миссия 3: «Собор Пепла»

- **Цели:** 1) Дойти до собора. 2) Погасить 3 пепельные жаровни (зеркально маякам М1; жаровня **[ЕСТЬ]** на макете). 3) Убить Пепельного Епископа.
- **Ход:** дорога паломников. Неф: 2 жаровни, гаргульи-статуи в нишах. Катакомбы: 1 жаровня, Сестра Обета. Когда погашены все три, открывается Алтарь. Погасить жаровню — взаимодействие 3 с, после него появляется пачка культистов-чемпионов.
- **Финал:** реплики в 3 фазах боя. После смерти босса текст-эпилог акта (сценарист), экран «Акт I пройден» со статистикой (время, убийства, смерти, лучший предмет) и тизер следующего акта.
- **Награда:** +1 очко навыка, 1 000 золота, гарантированный уникальный при первом убийстве, открытие режима «Охота».

### 8.5. Генерация уровней: **ручная с рандомизацией [ПРЕДЛОЖЕНИЕ]**

| Вариант | Плюсы | Минусы | Решение |
|---|---|---|---|
| Полностью процедурная (как D2) | Реиграбельность | Генератор, валидатор проходимости и стыковка тайлов отнимут около 4–6 недель разработчика. Труднее воспроизводить баги, сложнее контролировать атмосферу | В v2 |
| **Ручные карты в Tiled + рандом наполнения** | Быстро, полный контроль над атмосферой и темпом, баги воспроизводятся по сиду | Меньше реиграбельности | **v1** |

Что рандомизируется в v1:
- монстры: в каждой зоне 25–40 точек-маркеров с пулом типов, активна случайная часть (70%);
- 30% пачек становятся элитками в пределах лимитов из §8.1;
- сундуки: из 12 точек активны 6;
- имена и модификаторы уникальных.

Сид сессии показывается в меню ESC (нужен для отчётов о багах). В v1.1 можно добавить 2–3 ручных варианта планировки каждого подземелья с выбором случайного.

### 8.6. Пост-гейм «Охота»

После М3 любая зона перезаселяется при каждом входе через путевой камень, как новая игра в D2. Боссы убиваются повторно без гарантированного дропа. Это нужно для прокачки до 20 уровня и фарма уникальных.

## 11. Сохранение прогресса

**Решение v1: localStorage, без сервера [ПРЕДЛОЖЕНИЕ].** Аккаунты и бэкенд не нужны, игра раздаётся как статический сайт. Облачные сохранения переносим в v2.

| Параметр | Значение |
|---|---|
| Хранилище | `localStorage`, ключи `ashen.v1.slot1..3` + `ashen.v1.settings`. Объём одного слота < 100 КБ |
| Формат | JSON: `{schemaVersion, savedAt, playtime, character{class, level, xp, stats, unspent, skills{id:rank}, gold}, equipment{}, inventory[{itemId, x, y}], stash[], stashGold, belt[], items{id:{baseId, rarity, ilvl, affixes[{id, value}], uniqueId}}, quests{m1:{step, flags}}, waypoints[], respecUsed, firstKills[], settings}` |
| Что не сохраняется | Состояние монстров и лута на земле. При загрузке зоны генерируются заново, как новая игра в D2 |
| Автосейв | Переход между зонами, вход в город, шаг квеста, получение уровня, закрытие окна торговли или сундука, каждые 60 с, `beforeunload` |
| Защита от порчи | Запись в 2 ключа по очереди (`slotN.a` / `slotN.b`) с контрольной суммой. При загрузке берётся последний валидный |
| Миграции | `schemaVersion` + функции `migrate_vN_to_vN+1` |
| Экспорт и импорт | Кнопка «Экспорт» отдаёт файл `.json`, «Импорт» загружает его. Нужно тестировщикам и как защита от очистки браузера |
| Несколько вкладок | При старте ставим блокировку (`BroadcastChannel`). Вторая вкладка показывает «Игра уже открыта» |
| Античит | Не нужен: одиночная игра |

### 12.3. Ключевые чек-листы тестировщика

Тестировщику нужны дебаг-команды dev-сборки (консоль по клавише `~`): `level N`, `xp N`, `gold N`, `give <itemId|base> <rarity> <ilvl>`, `tp <zoneId>`, `god`, `kill_all`, `quest <m> <step>`, `sim_drop`, `show_hitboxes`, `seed N`, `fps`.

**A. Прохождение и прогрессия**
- [ ] Каждую миссию можно пройти от брифинга до награды. Нельзя застрять: двери, печать и колокол срабатывают и после смерти и загрузки посреди события.
- [ ] Уровень героя на выходе из М1/М2/М3 попадает в 6–7 / 11 / 15–16 (±1) при обычной игре без фарма.
- [ ] XP за уровень совпадает с §3.5. Штраф за разницу уровней работает.
- [ ] Очки: +5 и +1 за уровень, +1 за миссию. Сброс доступен ровно один раз.
- [ ] Ранг навыка нельзя поднять выше лимита уровня.

**B. Бой и формулы**
- [ ] Шанс попадания в пределах 5–95%. Окно C показывает тот же шанс, что получается на практике (100 ударов, допуск ±7%).
- [ ] Мана, КД и масштабирование всех 8 навыков на рангах 1, 5 и 10 совпадают с §3.6.
- [ ] Кап сопротивлений 75%, кап блока 50%, капы скоростей.
- [ ] Рывок не проходит сквозь стены, i-frames работают. Телепорт не переносит за стены и в недоступные места.
- [ ] Зелья: стек, КД 0,5 с, автозаполнение пояса.
- [ ] Смерть: −10% золота только из инвентаря, воскрешение в городе, босс полностью восстанавливается.

**C. Враги и боссы**
- [ ] Каждый AI ведёт себя по §5: бегство Падших, отскок гончих, дистанция лучников, засада гаргулий, воскрешение шамана.
- [ ] Монстры возвращаются, если увести их дальше 25 тайлов. Не застревают в геометрии.
- [ ] Все телеграфы видны до удара не меньше указанного времени.
- [ ] Фазы боссов включаются на нужных порогах HP. Лимит призванных соблюдается. Дверь арены открывается после победы и после смерти героя.
- [ ] TTK боссов на рекомендуемом уровне в пределах ±25% от §9.2.

**D. Лут, инвентарь, торговля**
- [ ] `sim_drop` на 10 000 бросков совпадает с таблицами §6.7 (±15%).
- [ ] Аффиксы в пределах диапазонов тира, нет запрещённых для слота, нет двух одинаковых.
- [ ] Род префикса согласуется с базой во всех 4 формах.
- [ ] Гарантии: редкий с Б1 и Б2 и уникальный с Б3 при первом убийстве.
- [ ] Сетка: размеры предметов, перетаскивание, замена при надевании, посох снимает щит (и что происходит, если щиту нет места).
- [ ] Торговец: цены по формуле, выкуп, обновление ассортимента не чаще раза в 10 минут.

**E. Сохранения**
- [ ] Автосейв на всех триггерах из §11. Перезагрузка страницы посреди боя теряет не больше 60 с прогресса.
- [ ] Порча одного ключа: загрузка из резервного. Импорт и экспорт. Сохранение старой версии мигрирует.
- [ ] Вторая вкладка не портит сохранение.
- [ ] Очистка данных сайта: корректный экран «Нет сохранений».

**F. UI / UX**
- [ ] Масштабы ×2, ×3 и ×4 и нестандартные разрешения (1366×768, 1440×900, 2560×1080) дают чёткие пиксели, без размытия и обрезанного HUD.
- [ ] Все тултипы, сравнение предметов, подписи по Alt без наложений.
- [ ] Горячие клавиши из §4.1. ПКМ не открывает меню браузера. Потеря фокуса ставит паузу.
- [ ] Тексты не вылезают за плашки (трекер ≤ 28 символов).

**G. Производительность и совместимость**
- [ ] Chrome, Edge, Firefox, Safari (macOS): 60 FPS в обычных боях, ≥ 45 FPS в фазе 3 Б3 с 25 врагами.
- [ ] Первая загрузка ≤ 10 с, переход между зонами ≤ 2 с.
- [ ] Нет утечки памяти за 60 минут игры (рост ≤ 50 МБ).

## 15. Приложение: данные для разработчиков

Все числа из документа задаются конфигами, не кодом. Файлы и ключевые поля:

| Файл | Содержимое |
|---|---|
| `data/stats.json` | Формулы §3.3 (коэффициенты), капы, кривая XP §3.5 |
| `data/skills.json` | `id, branch, tier, reqLevel, prereq, type, manaBase, manaPerRank, cooldown, values{base, perRank}, icon, anim, vfx` |
| `data/monsters.json` | `id, family, hpMul, dmgMul, xpMul, speed, attackCd, aggro, ai, abilities[], resist{}, sprite` + шкала §5.1 |
| `data/elites.json` | Типы элиток и модификаторы §5.3 |
| `data/bosses.json` | Фазы, пороги, способности, телеграфы |
| `data/items_base.json` | `id, slot, size{w,h}, reqLevel, dmg/armor, speed, gender, icon, price` |
| `data/affixes.json` | `id, type(prefix/suffix), stat, tiers[{ilvlMin, min, max}], slots[], names{m,f,n,pl}` |
| `data/uniques.json` | 8 уникальных |
| `data/droptables.json` | §6.7 |
| `data/zones/*.json` | Tiled-карты + слой маркеров спавна (`pool, chance, eliteAllowed`), сундуки, путевые точки, триггеры событий |
| `data/quests.json` | Шаги миссий, флаги, награды |
| `i18n/ru.json` | Все тексты сценариста по ключам |
